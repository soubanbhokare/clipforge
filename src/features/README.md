# CLIPFORGE features — planned homes

Each folder below is the future home of one product area. No feature
code lives here yet, and no empty component was created just to make
the tree look complete.

- `projects/` — project list, creation and ownership (Phase 3+)
- `video-input/` — video URL intake and authorised upload (Phase 3+)
- `clips/` — generated clips, review and selection (Phase 3+)
- `editor/` — timeline / clip editing (later phase, not Phase 2)
- `publishing/` — scheduling and official publishing APIs (later phase)
- `analytics/` — performance reporting on real published clips only

Until a phase starts, its pages render the honest placeholder in
`src/pages/PlaceholderPage.tsx` and show no fake data.
